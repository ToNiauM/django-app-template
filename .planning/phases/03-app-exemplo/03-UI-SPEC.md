# Phase 3 — UI Design Contract: App Exemplo

> Visual and interaction contract for Phase 3 (`apps/exemplo`). Generated by `gsd-ui-researcher`, consumed by `gsd-planner` and verified by `gsd-ui-checker`.

---

## Executive Summary

Phase 3 delivers the reference application (`apps/exemplo`) demonstrating the official CFC architecture:
1. **Reference CRUD**: Server-side paginated table with column sorting, live debounced search, multi-selection filters, and instant HTMX modal operations (Create, Edit, Delete).
2. **Analytical Dashboard**: KPI summary cards and Apache ECharts visualizations (Bar chart by Category, Donut chart by Status) powered exclusively by database ORM aggregations (`annotate`/`aggregate`), with drill-down links to filtered table views.
3. **Domain Isolation**: Fully decoupled, self-contained application using `django-simple-history` for audit trails, removable at any time without impacting system foundation.

## Spacing Scale

Declared values (multiples of 4 strictly enforced):

| Token | Value | Tailwind Class | Usage in Phase 3 |
|-------|-------|----------------|------------------|
| xs | 4px | `p-1`, `gap-1`, `space-y-1`, `mb-1` | Breadcrumb separators, inline badge padding, table header icon gaps |
| sm | 8px | `p-2`, `px-2`, `py-2`, `gap-2` | Filter pill gaps, button icon padding, form helper text spacing |
| md | 16px | `p-4`, `px-4`, `py-4`, `gap-4` | Table cell padding, KPI card inner padding, filter row gaps, modal section spacing |
| lg | 24px | `p-6`, `px-6`, `py-6`, `gap-6`, `mb-[24px]` | Page header bottom margin, modal body padding, dashboard grid gaps |
| xl | 32px | `p-8`, `gap-8` | Major container spacing, empty state vertical padding |
| 2xl | 48px | `p-12`, `gap-12` | Major section breaks (e.g. between dashboard sections) |
| 3xl | 64px | `p-16`, `gap-16` | Full-page empty states or hero layouts |

### Spacing Exceptions
- **44px Touch Target (`h-11`, `w-11`)**: Applied to all interactive mobile controls (menu triggers, mobile modal close buttons) to fulfill accessibility requirements.
- **56px Mobile Header (`h-14`)**: Standard top bar height on viewports `<768px`.
- **232px Fixed Aside (`w-[232px]`)**: Standard desktop navigation width.
- **2px Accent Strip (`w-[2px]`)**: Active navigation item vertical indicator bar.

### Accent (`brand`) Strict Whitelist
The accent color (`#1e40af` / `bg-brand` / `text-brand`) is **strictly reserved** for:
1. Primary action buttons ("Novo item", "Salvar item").
2. Active page button in the table pagination bar.
3. Active navigation item indicator strip in the sidebar (`w-[2px] bg-brand`).
4. Active filter tag / checkbox focus outline.
5. Primary metric bars / slices in analytical ECharts.
*Prohibited for: table row backgrounds, generic borders, secondary buttons, informational card headers.*

| State | Heading | Body Copy | Action Button |
|-------|---------|-----------|---------------|

### 3. Filter Bar Component

- **Search Input**:
  - HTML: `<input type="text" name="q" value="{{ request.GET.q }}" placeholder="Buscar por título ou descrição..." class="w-full rounded-sm border border-grid bg-surface px-3 py-2 text-sm text-ink placeholder:text-muted focus:border-brand focus:outline-none focus:ring-1 focus:ring-brand">`
  - HTMX trigger: `hx-trigger="input changed delay:300ms, search"`
- **Category & Status Multi-Select Filters**:
  - Rendered as dropdown or multi-checkbox list in responsive drawer / panel.
  - Checkbox labels styled with count indicators: `<label class="flex items-center gap-2 text-sm text-ink-2"><input type="checkbox" name="categoria" value="OPERACIONAL" ...> Operacional <span class="text-xs text-muted">(12)</span></label>`.
- **Form target**: `hx-target="#tabela-container"` with `hx-swap="innerHTML"` and `hx-push-url="true"`.

### 4. Data Table Component

- **Container**: `overflow-x-auto rounded-sm border border-grid bg-surface shadow-xs`.
- **Table Head (`<thead>`)**:
  - Classes: `bg-surface-2 border-b border-grid text-xs font-semibold text-ink-2 uppercase tracking-wider`.
  - Column headers with sort links: Clicking a header cycles sort order (`?ordem=titulo` -> `?ordem=-titulo` -> default) via HTMX.
  - Sort indicators: Ascending (↑), Descending (↓), or Neutral (↕).
- **Table Body (`<tbody>`)**:
  - Rows (`<tr>`): `border-b border-grid last:border-b-0 hover:bg-surface-2/60 transition-colors duration-150`.
  - Columns:
    1. **Título**: `text-sm font-semibold text-ink` with description preview in `text-xs text-ink-2 truncate max-w-xs`.
    2. **Categoria**: Badge neutral `px-2 py-0.5 rounded text-xs font-medium bg-surface-2 text-ink-2 border border-grid`.
    3. **Status**: Semantic badge with corresponding background, text and border tokens.
    4. **Valor**: `text-sm font-medium font-mono text-ink text-right tabular-nums` (formatted as `R$ 1.250,00`).
    5. **Prazo**: `text-sm text-ink-2 whitespace-nowrap` (`DD/MM/AAAA`).
    6. **Ações**: Action buttons (Editar / Excluir) aligned right.
- **Pagination Bar (`<tfoot>` or sub-bar)**:
  - Layout: `flex items-center justify-between border-t border-grid px-4 py-3 bg-surface`.
  - Info: `text-xs text-ink-2` -> "Exibindo **1** a **10** de **48** itens".
  - Pagination Controls: Previous button, number buttons (max 5 visible + ellipsis), Next button.

### 5. Modal Component (Create / Edit / Delete)

- **Backdrop**: `fixed inset-0 z-40 bg-black/40` with smooth fade.
- **Centering wrapper**: `fixed inset-0 z-50 flex items-center justify-center p-4`.
- **Dialog Box**: `relative w-full max-w-xl max-h-[90vh] flex flex-col rounded-sm border border-grid bg-surface shadow-2xl overflow-hidden` (`role="dialog" aria-modal="true"`).
- **Modal Header**: `flex items-center justify-between border-b border-grid px-6 py-4`.
  - Title: `text-xl font-semibold text-ink`.
  - Close button: `text-muted hover:text-ink text-xl leading-none p-1 rounded-sm hover:bg-surface-2`.
- **Modal Form Body**: `p-6 overflow-y-auto space-y-4`.
  - Form field rows: Label on top, input below, helper/error text underneath.
  - Field inputs: `w-full rounded-sm border border-grid bg-surface px-3 py-2 text-sm text-ink focus:border-brand focus:ring-1 focus:ring-brand`.
- **Modal Footer**: `flex items-center justify-end gap-3 border-t border-grid px-6 py-4 bg-surface-2/50`.
  - Cancel button: `button` with `border border-grid bg-surface text-ink-2 hover:bg-surface-2 px-4 py-2 rounded-sm text-sm font-semibold`.
  - Submit button: `button[type=submit]` with `bg-brand hover:bg-brand-hover text-white px-4 py-2 rounded-sm text-sm font-semibold shadow-xs`.
- **Alpine & HTMX Lifecycle**:
  - Modal container: `<div id="modal-container" x-data="{ aberto: true }" @keydown.escape.window="aberto = false; $el.innerHTML = ''"></div>`.
  - Response status 422: swaps new invalid form HTML into `#modal-container` while keeping focus on first invalid field.
  - Response status 200/204: closes modal by emptying `#modal-container` and triggers event `HX-Trigger: itemSalvo` to reload `#tabela-container`.

### 6. Dashboard KPI Cards & ECharts Integration

- **KPI Grid**: `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4 mb-6`.
  - Card: `rounded-sm border border-grid bg-surface p-4 flex flex-col justify-between`.
  - Label: `text-xs font-semibold uppercase tracking-wider text-muted`.
  - Value: `text-2xl font-bold tracking-tight text-ink mt-2 font-mono`.
  - Detail: `text-xs text-ink-2 mt-1 flex items-center gap-1`.
- **KPI Metrics**:
  1. **Total de Itens**: Count of all registered records.
  2. **Valor Acumulado**: Sum of all `valor` fields (`R$ X.XXX,XX`).
  3. **Itens Concluídos**: Count and percentage of concluded records.
  4. **Valor Médio**: Average value per item.
- **Charts Grid**: `grid grid-cols-1 lg:grid-cols-2 gap-6`.
  - Chart Container Card: `rounded-sm border border-grid bg-surface p-6 flex flex-col`.
  - Card Title: `text-base font-semibold text-ink mb-4`.
  - Chart DOM Element: `<div id="grafico-categoria" class="h-80 w-full" data-echart="dados-categoria"></div>`.
- **ECharts Palette Synchronization**:
  - Color map passed via `json_script`:
    - `brand`: `#1e40af`
    - `categories`: `["#1e40af", "#0284c7", "#0d9488", "#f59e0b", "#6366f1"]`
    - `surface`: `#fcfcfb`
    - `grid`: `#e4e2dd`
    - `ink`: `#0b0b0b`
    - `ink_muted`: `#77756f`
  - Tooltips styled with `backgroundColor: '#fcfcfb'`, `borderColor: '#e4e2dd'`, `textStyle: { color: '#0b0b0b', fontSize: 12 }`.
  - Click interaction: Clicking chart bars or donut sectors redirects with query parameter filter applied (`window.location.href = "{% url 'exemplo:item_listar' %}?categoria=" + encodeURIComponent(params.name)`).
  - Responsive resize listener: `window.addEventListener('resize', () => { chartInstance.resize(); })`.
