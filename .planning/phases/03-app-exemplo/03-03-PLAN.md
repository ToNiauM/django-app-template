## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Django Templates → Browser JavaScript Execution | Serialização de dados agregados do backend para scripts de visualização gráfica |
| URL Query String → CRUD Filters | Redirecionamento por drill-down do ECharts para o CRUD via querystring `?categoria=...` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-10 | Information Disclosure / XSS | `apps/exemplo/templates/exemplo/dashboard.html` | mitigate | Uso exclusivo do filtro `json_script` do Django para emitir datasets JSON em tags `<script type="application/json">` escapadas, evitando XSS por interpolação de strings em JavaScript inline (D-31) |
| T-03-11 | Denial of Service | `apps/exemplo/views.py` (`dashboard_view`) | mitigate | Todas as agregações executadas no banco PostgreSQL via `.aggregate()` e `.annotate()` em consultas $O(1)$ em memória do servidor, prevenindo exaustão de memória Python em grandes volumes de dados (D-30) |
| T-03-12 | Elevation of Privilege | `apps/exemplo/views.py` (`dashboard_view`) | mitigate | Proteção com `@login_required` garantindo que apenas usuários autenticados acessem os indicadores analíticos |
| T-03-13 | Architecture Drift | `apps/exemplo/` | mitigate | Teste automatizado `test_isolamento.py` bloqueia introdução acidental de dependências reversas de `core/` sobre o app exemplo (EX-04) |
</threat_model>
