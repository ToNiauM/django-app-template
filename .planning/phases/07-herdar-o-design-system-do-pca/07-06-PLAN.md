### Forma do `paleta_graficos` servido pelo Django

Decisão de planejamento (discricionária, dentro de D-84/D-85): o servidor entrega a rampa
**nos dois temas**, derivada da mesma `core.tema.familia_marca(settings.COR_PRIMARIA)` que
alimenta o `<style>` de `base.html`. Duas fontes do mesmo valor não podem divergir porque
são a mesma função.

```
paleta_graficos = {
    "rampa_status": {
        "claro":  [seq-600, seq-450, seq-300, brand-tint],
        "escuro": [seq-600:escuro, seq-450:escuro, seq-300:escuro, brand-tint:escuro],
    }
}
```

Quatro cores porque `StatusChoices` tem **quatro** valores (`RASCUNHO`, `EM_ANDAMENTO`,
`CONCLUIDO`, `CANCELADO`) — o texto da pesquisa fala em três; a fonte é
`apps/…/exemplo/models.py:18-22`. A rampa é sequencial (monocromática) de propósito: um
template não consegue escolher matizes categóricos que sobrevivam a **qualquer**
`cor_primaria` e continuem legíveis para daltônicos; a rampa deriva sozinha e todo derivado
ganha um donut coerente com a própria marca sem decidir nada (D-84).

Nenhum hex literal em Python fora de `core/tema.py`.
