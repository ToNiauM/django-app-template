## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.env` → shell/crontab | Agenda, retenção e credenciais chegam ao serviço backup |
| Serviço backup → PostgreSQL/R2 | Dump e credenciais cruzam rede Docker e armazenamento externo |
| Compose → Docker host | Project name, bind e volume determinam isolamento dos recursos locais |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-12 | Elevation of Privilege | cron do backup | high | mitigate | EntryPoint valida inteiros/faixas antes do crontab; nenhum valor vira comando shell livre |
| T-04-13 | Information Disclosure | credenciais R2/PostgreSQL | high | mitigate | Credenciais existem somente no `.env`/environment, fora de answers, imagem e logs |
| T-04-14 | Elevation of Privilege | porta web | high | mitigate | Publish conserva fallback 127.0.0.1 e container mantém porta interna fixa |
| T-04-15 | Denial of Service | backup antes do banco | medium | mitigate | `depends_on` usa healthcheck e `init: true` evita crash loop do dcron |
| T-04-16 | Tampering | teste de retenção | high | mitigate | Prefixo slug+PID, bloqueio de daily/weekly e trap limitam remoções ao namespace descartável |
</threat_model>
