## What Was Built

### input.css (Task 1 — 102 linhas acrescentadas, 0 removidas)

- **color-scheme**: `light` no `:root`, `dark` no `[data-tema="escuro"]` — date picker, select e scrollbar padrão acompanham o tema sem CSS por controle.
- **accent-color**: `var(--cor-brand)` no `:root` — checkbox/radio/progress na cor da marca nos dois temas; o override de runtime da COR_PRIMARIA (base.html) atualiza tudo sozinho.
- **::selection**: fundo `var(--cor-brand-tint)`, sem fixar `color`.
- **Scrollbar**: `scrollbar-width: thin; scrollbar-color: var(--cor-grid) transparent;` no `html` (propriedade herdada).
- **.results**: `font-variant-numeric: tabular-nums` dentro do bloco existente em `@layer components`; regra solta FLAT `.results tbody tr:hover { background-color: var(--cor-surface-2); }` — sem nesting (build tailwindcss puro), sem markup.
- **h1**: `text-wrap: balance` no `@layer base` existente (junto do `:focus-visible`).
- **Movimento** (tudo dentro de `@media (prefers-reduced-motion: no-preference)`): `@view-transition { navigation: auto; }`; `@keyframes surgir-modal` (opacity 0→1 + translateY(6px)/scale(0.98)) aplicado a `#modal-container > *` em 150ms ease-out; transições de cor de 150ms para `a, button, .btn, .form-row` com propriedades explícitas.
- **.btn:active**: `transform: translateY(1px)` FORA do media query (transform instantâneo é inofensivo com reduced-motion).
